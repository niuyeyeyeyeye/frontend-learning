## 每天节奏（2026-10-05 按"真实练习耗时"校准）

| 时间段 | 安排 |
|---|---|
| 周一 ~ 周五晚上（2–2.5h） | **1h 算法（1 题做透）** + 1h 学习/练习 + 15 min 笔记 |
| 周六（4h） | 集中做练习 / 项目 |
| 周日（4h） | 项目 + **30 min 算法复习日**（重做本周 1–2 题）+ 30 min 复盘 |
| 每 3–4 周 | 留 1 周缓冲：只复习补漏，不学新内容 |

### 吞吐量基准（照这个估，别照"文件个数"估）

- **一道练习题 ≈ 20–25 分钟**（第一次动手就是这个速度，很正常）
- 一个学习文件 ≈ 讲解 30 min + 练习 3~4 道 × 20 min ≈ **1.5–2.5 小时**
- 所以**每周的真实容量 = 2 个学习文件 + 每天 1 题算法**（正好 15–20h）
- 你的实际节奏（1–1.5 周 / 主题）**本来就是这个容量的正常表现**，不用焦虑，也别硬塞 3 个文件

### 练不完怎么办（三条原则）

1. **每道练习 20–25 分钟时间盒**：到点没做出来 → 看答案 → 合上重写 → 往下走
2. **每个文件"必做 2 题 + 选做 N 题"**：选做不做**不算欠债**（练习是手段，掌握才是目标）
3. **宁可少做、做透**：一道题能独立默写，胜过三道题抄过答案

> 学校作业/考试重的那周：**直接跳过学习，用掉缓冲周**，不要熬夜赶进度。

## 学习方法

- 视频正确用法：先看 10 分钟 → 关掉自己写 → 卡住再看 → 写完对比
- 资料：[MDN](https://developer.mozilla.org/zh-CN/docs/Web/JavaScript/Guide)、[现代 JavaScript 教程](https://zh.javascript.info/)、[TypeScript 官方手册](https://www.typescriptlang.org/docs/handbook/intro.html)、[React 中文文档](https://zh-hans.react.dev/)
- 每个 day 的笔记写在对应文件夹的 `笔记.md` 里，周日回看
- **每完成一次练习就 git commit**（Git 在 day7 学，之后养成习惯）
