## 四、核心概念 2：环境变量

```tsx
const mode = import.meta.env.MODE      // development / production
const isDev = import.meta.env.DEV      // boolean
const base = import.meta.env.BASE_URL  // 部署基础路径
```

### ⭐ 唯一必须记住的规则：`VITE_` 前缀

| .env 里写 | 前端能读吗 |
|---|---|
| `VITE_API_BASE_URL=/api` | ✅ 能 |
| `API_SECRET=sk-xxx` | ❌ 读不到（故意的） |

### ⚠️ 更重要的一条：`VITE_` 变量会**打包进 JS**

```
.env 里写 VITE_API_SECRET=sk-live-xxx
→ 构建后 dist/assets/index-xxx.js 里能直接搜到
→ 任何人 F12 → Sources 都能看到
```

**前端代码是"发给用户的文件"，不是跑在服务器上的代码。** 密钥只能放后端。

### 文件层级

| 文件 | 提交 git？ | 用途 |
|---|---|---|
| `.env` | ✅ | 所有环境共用 |
| `.env.local` | ❌（已进 .gitignore） | 你机器上的覆盖值 |
| `.env.development` / `.env.production` | ✅ | 分模式 |
| `.env.example` | ✅ **必须** | 模板，告诉同事要填什么 |

> ⚠️ **改完 .env 必须重启 `npm run dev`** —— 环境变量在启动时读进内存并做静态替换，热更新不会重读。人人都会踩一次。

## 五、核心概念 3：构建与部署

### `npm run build` 做了两件事

```
"build": "tsc --noEmit && vite build"
         ↑ 先类型检查      ↑ 再打包（&& 表示前面失败就停）
```

产物：

```
dist/
├── index.html                 ← 只有一个 HTML
└── assets/
    ├── index-C3xK9pQa.js     ← 文件名里是内容哈希 → 内容变了文件名就变 → 缓存自动失效
    └── index-Df8Lm2Zx.css
```

### 为什么必须有 `npm run preview`

| | `npm run dev` | `npm run preview` |
|---|---|---|
| 代码 | 原样加载 | 打包 + 压缩 |
| StrictMode 双渲染 | ✅ 有 | ❌ 没有 |
| 性能数字能信吗 | ❌ | ✅ 最接近线上 |
| 环境变量 MODE | development | production |

**Day10 说的"性能要 build 之后再看"，指的就是 preview 这个阶段。**

### ⭐ 上线第一个坑：刷新页面 404

```
浏览器请求  /day7/users/2
服务器找文件 dist/day7/users/2  ← 不存在！只有 index.html
→ 404
```

解决：让服务器把所有路径都返回 `index.html`（根目录的 `vercel.json` 已经配好）：

```json
"rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
```

不同平台名字不同：**Nginx** 是 `try_files $uri /index.html`，**Vercel** 是 rewrites，**Netlify** 是 redirects。

> 面试常问："SPA 部署后刷新 404 怎么办？" —— 就是这个答案。
> 还要能分清：**平台 404**（服务器没把请求交给你）vs **你的 NotFound 组件**（请求进来了但路由没匹配）。

### 部署三步（都不花钱）

```powershell
# ① 本地先验证（必须）
npm run build
npm run preview          # 在 preview 地址里手动刷新 /day7/users/2，看会不会 404

# ② 推到 GitHub
git add .
git commit -m "feat: React 阶段项目"
git remote add origin https://github.com/<你的用户名>/react-learning.git
git branch -M main
git push -u origin main
```

③ 打开 vercel.com → GitHub 登录 → **Add New → Project** → 选仓库 →
**Root Directory 填 `react-learning`**（你的项目在子目录，这一步最容易漏）→ Deploy。

等 1~2 分钟拿到 `https://xxx.vercel.app` —— **这就是简历上的线上链接**。
