## 三、三个必须记住的规则

### ① 事件绑定：传函数引用，不传函数调用

```tsx
<button onClick={handleClick}>   ✅ 点击时才调用
<button onClick={handleClick()}> ❌ 渲染时就调用，把返回值当处理函数
<button onClick={() => handleClick(id)}>  ✅ 需要传参时用箭头函数包一层
```

**怎么自己发现这个错**：如果写成 `onClick={fn()}`，控制台会在**每次渲染**时打印日志（而不是点击时）。

### ② 改 state 必须用 set 函数

```tsx
count++                  ❌ React 不知道你改了，页面不会更新
setCount(count + 1)      ✅
arr.push(x)              ❌
setArr([...arr, x])      ✅ 不可变更新（你 Day6 学过）
obj.name = 'x'           ❌
setObj({ ...obj, name: 'x' })  ✅
```

### ③ `&&` 前确保左边是 boolean

```tsx
{count && <p>有 {count} 条</p>}      ❌ count 为 0 时会渲染出 "0"
{count > 0 && <p>有 {count} 条</p>}  ✅
{list.length > 0 && ...}             ✅
```

## 六、常见问题

| 现象 | 原因 |
|---|---|
| 输入框**输不进去** | 只写了 `value` 没写 `onChange` → 值被 state 锁死 |
| 点按钮**没反应** | ① 写成 `onClick={fn()}` ② 或者 handler 里忘了调 set 函数 |
| 页面**不更新** | 直接改了 state（`count++` / `arr.push`），没用 set |
| 温度显示 `NaN` | 输入框是空字符串，`Number('')` 是 0 但 `Number('abc')` 是 NaN，要判断 |
| 页面刷新了 | 表单提交没写 `e.preventDefault()` |

## 七、今天要真正想明白的一句话

> **你不再"操作 DOM"了。**
>
> 你 Day6 写的 `list.innerHTML = ...`、`appendChild`、`classList.toggle`，在 React 里**全都不写**。
> 你只做一件事：**改 state**。剩下的（更新 DOM）React 替你干。

这就是为什么 React 里的代码会越来越"像在描述数据"，而不是"像在操作页面"。
