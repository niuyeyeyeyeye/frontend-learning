## 三、三件必须记住的事

### ① key 用什么？

| 场景 | 用什么做 key |
|---|---|
| 数据有 `id`（最常见） | `key={item.id}` ✅ |
| 没有 id | 在数据里**自己生成一个**（`{ id: nextId++, ...}`）✅ |
| 列表**不会增删、不会重排** | 可以用 `index` ⚠️（静态配置列表） |
| 有增删/排序 | **绝对不能用 index** ❌ |
| 任何情况 | **不要用 `Math.random()`** ❌（每次渲染都变 → 列表整个重建） |

### ② 不可变更新速查表

| 操作 | ❌ 错 | ✅ 对 |
|---|---|---|
| 添加 | `todos.push(x)` | `setTodos([...todos, x])` |
| 删除 | `todos.splice(i, 1)` | `setTodos(todos.filter(t => t.id !== id))` |
| 修改一项 | `todos[i].done = true` | `setTodos(todos.map(t => t.id === id ? {...t, done: true} : t))` |
| 排序 | `todos.sort(...)` ← **sort 会改原数组！** | `setTodos([...todos].sort(...))` |
| 清空已完成 | 循环 splice | `setTodos(todos.filter(t => !t.done))` |

### ③ 表单两个必备动作

```tsx
<form onSubmit={(e) => { e.preventDefault(); addTodo() }}>
  <input value={input} onChange={(e) => setInput(e.target.value)} />
</form>
```
- `e.preventDefault()` → 否则提交后**页面刷新**
- `value` + `onChange` → 受控组件，输入框的值由 state 决定

## 六、对比一下你在 Day6 写的原生 JS 版本

| Day6 原生 JS | Day3 React |
|---|---|
| `list.innerHTML = ''` 手动清空 | 不需要 |
| `document.createElement('li')` | 不需要 |
| `appendChild` | 不需要 |
| 手动同步 localStorage | `useState` 自动管理 |
| 删一条要手动 `parentElement.remove()` | `setTodos(todos.filter(...))` |
| **写完还要自己检查 DOM 有没有对** | **改数据，页面自动对** |

> 这就是 React 的价值：**你只描述"数据是什么"，不描述"怎么改页面"。**
