## 二、核心概念 1：useRef 是"不会触发渲染的容器"

```tsx
const ref = useRef(0)
ref.current += 1        // ⚠️ 改它不会触发重新渲染
```

| | useState | useRef |
|---|---|---|
| 改它会怎样 | **触发重新渲染** | **不触发渲染** |
| 值会保持吗 | 保持 | 保持（同一个 ref 对象） |
| 什么时候用 | 影响 UI 显示的数据 | 定时器 id、DOM 引用、上一次的值、内部数据 |

**三个典型用途**：
1. **存定时器 id**：需要在别的函数里 `clearInterval` 时
2. **访问 DOM**：`<input ref={inputRef} />` → `inputRef.current?.focus()`
3. **保存上一次的值**：用 `useRef` + `useEffect`（见 `01-useRef基础.tsx` 的写法）

## 三、核心概念 2：自定义 hook —— 复用逻辑，**不复用状态**

```tsx
function useCounter(initial = 0) {
  const [count, setCount] = useState(initial)
  const increment = () => setCount(c => c + 1)
  return { count, increment }
}
```

**两条规则**：
1. **函数名必须以 `use` 开头**（React 靠这个来检查 hook 规则）
2. **内部可以调用其他 hook**（useState / useEffect / 别的自定义 hook 都可以）

### ⚠️ 最容易误解的一点

> **自定义 hook 复用"逻辑"，不复用"状态"！**

```tsx
<CounterPanel />   // count = 3
<CounterPanel />   // count = 0  ← 两个组件各有一份独立的 count
```

**想共享状态**要用 Context（明天 Day6）或 Zustand（Day8）。

## 七、一个你会遇到的疑问：useRef 和 useDebounce 有什么关系？

`useDebounce` 的实现是：

```tsx
function useDebounce<T>(value: T, delay = 300): T {
  const [debounced, setDebounced] = useState(value)
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay)
    return () => clearTimeout(id)   // ⭐ 每次 value 变了，清掉上一个定时器
  }, [value, delay])
  return debounced
}
```

**为什么不需要 useRef 存定时器 id？** 因为定时器是在 **effect 内部**创建的，清理函数也在同一个 effect 里，`id` 通过闭包就能拿到 —— **不需要跨函数访问，所以不用 ref**。

> **判断标准**：定时器 id 要不要在**别的函数**里用？
> - 只在 effect 内部用 → 闭包就够了，不用 ref
> - 要在按钮点击等地方用 → 必须用 `useRef` 存
