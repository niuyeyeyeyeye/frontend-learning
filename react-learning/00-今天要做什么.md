## 三、今天的三个文件（按顺序）

### ① `01-JSX基础.tsx` —— 读，并在浏览器里对照看

要记住的 5 条规则：

| 规则 | 说明 |
|---|---|
| `{}` 里写 JS **表达式** | `{1 + 1}`、`{name.toUpperCase()}`，**不能写 if/for 语句** |
| 属性用 camelCase | `className`（不是 class）、`htmlFor`、`onClick` |
| 只有一个根元素 | 多个用 `<>...</>`（Fragment）包起来 |
| 注释写 `{/* ... */}` | 不能用 `//` 或 HTML 注释 |
| style 是对象 | `style={{ color: 'red' }}`（两个花括号） |

**条件渲染**学会两种：`cond ? A : B` 和 `cond && A`。
**列表渲染**记住：`{list.map(item => <Tag key={item.id} />)}` —— **key 必须有**。

### ② `02-组件与props.tsx` —— 读，重点看 TS 类型怎么标

| 知识点 | 你会看到 |
|---|---|
| 组件就是**首字母大写**的函数 | `function Hello()` |
| props 用 interface 描述 | `interface UserCardProps { name: string; age: number; tags?: string[] }` |
| 可选 props | `tags?: string[]`（Day2 学的） |
| 默认值 | `{ variant = 'primary', ... }` 解构赋默认值 |
| 字面量联合限制取值 | `variant?: 'primary' \| 'ghost'` |
| children | `children: ReactNode` —— 组件"夹层"里的内容 |
| 组件组合 | `TodoList` 里用 `TodoItem` |

> ⭐ **props 是只读的**：子组件不能改父组件传进来的数据。想改数据，必须由父组件传一个"改的方法"下来（明天学 `useState` 就懂了）。

## 五、常见问题（卡住先看这里）

| 现象 | 原因 / 解决 |
|---|---|
| 打开 5173 是**白屏** | 打开浏览器控制台（F12）看红色报错；大概率是组件里有语法错误 |

## 六、今天要理解的一句话

> **React 的核心思想：UI 是"状态的函数" —— `UI = f(state)`。**
> 你现在看到的页面，完全是由数据（props）决定长什么样的。
> 明天学 `useState` 之后，你就会发现：**改数据 → 页面自动变**，不用手动操作 DOM。

这就是为什么你之前在待办列表里手写的 `innerHTML`、`appendChild` 这些操作，
到 React 里**全都不需要了** —— 那些正是 React 帮你做的事。
