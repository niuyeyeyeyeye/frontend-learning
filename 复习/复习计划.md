# 复习计划（找回练习手感）

> 2026-08-28 起，开学前 + 开学后第一周
> 目标：把"忘掉的练习"重新变成"能写出来的能力"，不是重新学一遍

## 先说结论（很重要）

- **忘掉练习 ≠ 没学会**。第一次学是"理解"，第二次重做是"恢复记忆"，速度是第一次的 1/3。
- 最有效的恢复方式**不是重看视频**，而是**检索练习**：先自己写 → 卡住 → 再看答案。
- 复习要**间隔重复**：今天做完，隔 1 天、隔 3 天各再测一次，才能真正进长期记忆。

## 复习安排（宽松版，别贪多）

| 时间 | 做什么 | 时长 |
|---|---|---|
| 今天 | 复习-01 JS 基础（Part A 自测 + B1~B4） | 45~60 min |
| 明天 | 复习-01 剩余（B5~B7）+ 隔天重测 Part A | 45~60 min |
| 后天 | 复习-02 Flexbox 和 Grid 的 4 个练习 | 45~60 min |
| 开学第一周 | 每天 30 min：从两个复习文件里轮着重做 1~2 道题 | 30 min/天 |

## 怎么判断"恢复好了"

不看答案，10 分钟内能写出：
1. filter / map 各一行（数组操作）
2. 一个 flex 居中（`justify-content` + `align-items`）
3. 一个 grid 三列（`repeat(3, 1fr)`）

做到这个标准，就可以回到 `第二周/day3-响应式设计/` 继续，忘掉的部分边做边补。

## 之后怎么防止再忘

- 每学完一个 day，隔 3~5 天回头重做里面 1 道练习（5 分钟就够）
- 每周日晚 30 分钟复盘本周，顺手重做最不熟的一道题
- 所有练习放进 Git，隔周 `git log` 看自己写了多少——进度感就是动力
