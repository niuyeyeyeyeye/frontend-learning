## 核心知识点（背下来）

### 1. 媒体查询

```css
/* 桌面优先（从大到小写） */
@media (max-width: 600px) { ... }

/* 移动优先（从小到大写，推荐） */
@media (min-width: 600px) { ... }

/* 范围写法（新语法，可读性好） */
@media (601px <= width <= 900px) { ... }
```

### 2. 单位

- `px`：固定像素，不响应
- `rem`：相对 `html` 的 font-size，改一处全站缩放（1rem = 16px 默认）
- `vw`：1vw = 视口宽度的 1%，直接跟随屏幕
- `clamp(最小, 理想, 最大)`：流式但有上下限，最常用

### 3. 移动优先三步骤

1. 默认样式 = 手机端（1 列、按钮全宽、字号 ≥16px 防 iOS 缩放）
2. `@media (min-width: 600px)` → 平板（2 列、横排导航）
3. `@media (min-width: 960px)` → 桌面（3 列、大留白）

### 4. 常用断点（经验值）

| 设备       | 宽度          |
| -------- | ----------- |
| 手机竖屏     | 0 ~ 480px   |
| 手机横屏/小平板 | 481 ~ 767px |
| 平板       | 768 ~ 991px |
| 桌面       | ≥ 992px     |

### 5. 必带标签

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

没有它，手机浏览器会把页面按桌面宽度缩小显示。
