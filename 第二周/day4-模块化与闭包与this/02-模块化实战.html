Day4-2：模块化实战

这个页面的数据由 main.js 渲染，它又 import 了 utils.js。

    ⚠️ 模块没加载成功

    原因：ES 模块不能用 file:// 直接双击打开（浏览器会报 CORS 错误），必须通过本地服务器访问。

    解决方法（任选一个）

    1. VS Code：装 Live Server 插件 → 右键本文件 → Open with Live Server
    2. 命令行（推荐，已确认你装了 Python）：
      ① 在本文件夹空白处按住 Shift + 右键 → "在此处打开 PowerShell"
      ② 输入 python -m http.server 8080 回车
      ③ 浏览器打开 http://localhost:8080/，点击 02-模块化实战.html
      ④ 学完在终端按 Ctrl + C 关掉

    动手练习

    1. 在 utils.js 里新增一个 export function discount(price, rate)，返回打折后价格
    2. 在 main.js 里 import 它，并给购物车总价打 8 折显示
    3. 把 utils.js 里的 export { multiply, subtract } 注释掉， 刷新页面看控制台的报错 —— 体验"没导出就用不了"
    4. 挑战：新建 string-utils.js，导出 2 个字符串处理函数，在 main.js 里用上
