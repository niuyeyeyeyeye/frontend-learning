5 个空函数 + 自动判分。写之前先别看 04，写完再对比

只有一句话要记：
用户动作 → 改内存里的数据 → 写进 localStorage → 重画界面
顺序不能反。新手两大错：只改 DOM 不存数据（刷新就没）；只存数据不重画（页面不动）。

搜索历史 （最多 5 条，最新的排最前，重复的只留一条）

还没有搜索记录

你要写的 5 个函数

  1. loadHistory() —— 从 localStorage 读出来，赋给 historyList。读不到就给 []
  2. saveHistory() —— 把 historyList 写进 localStorage
  3. addHistory(kw) —— 核心：去空格 → 空的就 return → 去重 → 最新在前 → 最多 5 条 → 存 → 重画
  4. renderHistory() —— 把 historyList 画成标签：<span class="tag" data-keyword="词">词</span>；没记录时显示空状态
  5. clearHistory() —— 清空内存 + 删掉存储 + 重画
