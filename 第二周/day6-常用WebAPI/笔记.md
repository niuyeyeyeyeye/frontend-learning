## 一、定时器

```js
const t = setTimeout(fn, 1000, arg1)   // 延迟执行一次，返回 id
clearTimeout(t)                        // 取消
const i = setInterval(fn, 1000)        // 每隔一段时间执行
clearInterval(i)                       // 一定要清，否则一直跑
```

- 执行顺序：**同步代码 > 宏任务（定时器回调）**，`setTimeout(fn, 0)` 也要等同步代码跑完
- 定时器不准：主线程被阻塞时会延后；精确动画用 `requestAnimationFrame`
- 循环 + 定时器的闭包坑：`var` 输出 `4 4 4`，`let` 输出 `1 2 3`（Day4 学过）

## 二、本地存储

| 特性 | localStorage | sessionStorage | cookie |
|---|---|---|---|
| 生命周期 | 永久 | 关标签页就没 | 可设过期 |
| 容量 | ~5MB | ~5MB | ~4KB |
| 随请求发送 | 否 | 否 | **是** |
| 作用域 | 同源所有标签页 | 仅当前标签页 | 同源 + 路径 |

```js
localStorage.setItem('k', JSON.stringify(obj))   // 只能存字符串！
JSON.parse(localStorage.getItem('k'))            // 取出来要 parse
localStorage.removeItem('k')                     // 删
localStorage.clear()                             // 清空（慎用）
localStorage.length / localStorage.key(i)        // 遍历
```

**坑**：读不存在的 key 返回 `null`（不是 undefined）；存对象必须序列化；存 `undefined` 会变成字符串 `"undefined"`；循环引用会报错；不要存 token 明文（XSS 能偷）；`storage` 事件可以跨标签页通信。

## 三、防抖与节流（背下来）

```js
// 防抖：等你停下来才执行（只执行最后一次）
function debounce(fn, delay = 300) {
  let timer = null
  return function (...args) {
    clearTimeout(timer)
    timer = setTimeout(() => fn.apply(this, args), delay)
  }
}

// 节流：固定时间内最多执行一次（时间戳版，首次立即执行）
function throttle(fn, interval = 300) {
  let last = 0
  return function (...args) {
    const now = Date.now()
    if (now - last >= interval) {
      last = now
      fn.apply(this, args)
    }
  }
}
```

| | 防抖 debounce | 节流 throttle |
|---|---|---|
| 行为 | 连续触发只认最后一次 | 固定频率放行 |
| 场景 | 搜索联想、表单校验、按钮防连点 | 滚动加载、resize、拖拽、鼠标跟随 |
| 口诀 | 安静下来才算数 | 像水滴一样稳定输出 |

**关键**：两个实现都靠**闭包**保存 `timer` / `last`（Day4 的闭包 + Day4 的 `apply` 在这里全用上了）。
