### [1] 两数之和 · 简单 · 2026-10-05

- 思路：用内置Map对象存放差和下标
- 踩的坑：误以为下标必须作为键
- 复杂度：时间 O(n) / 空间 O(n)
- 3 天后复习：✅⬜


### [58] 字母异位词分组 · 中等 · 2026-10-6
- 思路：把原数组的字符串用sort()方法排序放到新数组，把新数组当键并且属性值赋值为空数组，相同的键push()对应的原数组的值
- 踩的坑：数组中不能有null
- 复杂度：时间 O(n* k*logk) / 空间 O(n *k)
- 3 天后复习：✅⬜
- 复习结果：还是不会

### [128] 最长连续序列 · 中等 · 2026-10-7
- 思路：将数组存到set对象里，用set完成去重，然后算出每个序列的长度，选出最长的
- 踩的坑：判断条件不能是`数组 === []`,只能用长度来判断，set对象可以用for of循环
- 复杂度：时间 O(n) / 空间 O(n)
- 3 天后复习：✅⬜
- 复习结果：写的很慢，set本身是可迭代对象，可以用for of遍历

### [283] 移动零 · 简单 · 2026-10-08

- 思路：两个指针，一个左指针一个右指针，开始都指向0，右指针循环自增直到找到非零就和左指针交换，交换后左指针自增，如此循环直到循环结束
- 踩的坑：filter不会改变原数组，不能随便判断条件，要考虑undefined和其他边界值
- 复杂度：时间 O(n) / 空间 O(1)
- 3 天后复习：✅⬜
- 复习结果：写题太久，不能直接给右指针赋值0，因为左右指针可能指向同一元素，要老实交换

### [11] 盛最多的水 · 中等 · 2026-10-9
- 思路：两个指针一个最左一个最右，先把面积存起来，再把左右两边小的指针往另一个指针移动，直到指针相撞
- 踩的坑：用for就会多出一个变量，双指针用while比较好
- 复杂度：时间 O(n) / 空间 O(1)
- 3 天后复习：✅⬜
- 复习结果：在高度比较中用let定义面积area，导致外部访问不到

### [15] 三数之和 · 中等 · 2026-10-10
- 思路：将数组排序，固定一个数，两个指针指向其余数组的首尾，三数之和大于零就改右指针，否则改左
- 踩的坑：指针在外层循环结束后没有重置，三个数的和没有提前算好
- 复杂度：时间 O(n^2) / 空间 O(1)
- 3 天后复习：⬜⬜

### [3] 无重复字符的最长子串· 中等 · 2026-10-11

- 思路：遍历字符串，定义一个指针指向前一个重复元素的后一位，用下标i和指针算出字串长度
- 踩的坑：typescript即使用条件判断了类型，会undefined还是要用空值合并??或断言!。指针要在i下标后面
- 复杂度：时间 O(n) / 空间 O(k)
- 3 天后复习：⬜⬜

### [438] 找到字符串中所有字母异位体· 中等 · 2026-10-12

- 思路：使用滑动窗口进一个数查一个数，窗口大于字符串时自增左指针，控制合格数，等于字符串数量时推入结果
- 踩的坑：窗口不能重复创建
- 复杂度：时间 O(n) / 空间 O(k)
- 3 天后复习：⬜⬜

### [560] 和为K的子数组· 中等 · 2026-10-13

- 思路：遍历数组，将数组的前n项和存入map中通过当前元素和K的差查找前面出现过的数，并将数进行累加
- 踩的坑：先存入再查，如果K是0将会把每一个数组自己多算一遍
- 复杂度：时间 O(n) / 空间 O(n)
- 3 天后复习：⬜⬜
