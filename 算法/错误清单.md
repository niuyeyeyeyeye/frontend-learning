## 一、越界 / 空值 ⚠️⚠️⚠️（出现 7 次，你最贵的坑）

**这不是"某题不会"，是一个跨题的坏习惯。**

| 题 | 你当时踩的坑 |
|---|---|
| [21] 合并两个有序链表 | 循环条件两指针有一个是空的，指针为空了取 `val` 会报错 |
| [2] 两数相加 | 不熟递归，`null` 还 `.val` |
| [19] 删除倒数第 N 个节点 | 没有判断右指针为 `null` 的情况 |
| [283] 移动零 | 要考虑 `undefined` 和其他边界值 |
| [56] 合并区间 | 直接判断相邻区间，导致 `i` 超出数组范围 |
| [128] 最长连续序列 | 判断空数组用 `数组 === []`（永远 false），要用 `length` |
| [54] 螺旋矩阵 | 没有注意"只有一排/一列"时的情况 |

### 口诀
> **先判 null，再取 val；判空用 length，别用 `=== []`。**

### 自检（写完每题花 10 秒扫一遍）
- 每处 `.val` / `.next` 前面，有没有判 `null`？
- 每个 `arr[i]` / `arr[i+1]`，循环边界有没有保证 `i+1 < len`？
- 空数组 / 单元素 / 只有一排，这三组输入想过吗？

## 二、JS 语言细节（一次性学会，永久解决）

**这类坑最划算：学会一次，以后不再犯。** 建议二刷前把这 10 条读一遍。

| 题 | 你当时踩的坑 | 正确做法 |
|---|---|---|
| [15] 三数之和 | `sort()` 没有传递比较函数 | `sort((a,b)=>a-b)`，否则按字符串排（`10 < 9`）|
| [438] 字母异位词 | 不能 `'a'-'b'` 求值 | `s.charCodeAt(i) - 'a'.charCodeAt(0)` |
| [36] 有效的数独 | 不知道 `Array.from` | `Array.from({length:9}, () => new Set())` |
| [12] 整数转罗马 | 不知道取各位 | `Math.floor(n / 10)` + `n % 10` |
| [58] 字母异位词分组 | `Map` 不能用 `Object.values()` | `map.values()` / `[...map.values()]` |
| [128] 最长连续序列 | 不知道 set 可迭代 | `for (const x of set)` |
| [283] 移动零 | `filter` 不会改变原数组 | 要么用返回值，要么 `nums.length = 0; nums.push(...)` |
| [187] 重复 DNA 序列 | 位运算忘记赋值 | `x |= (1 << k)` 别写成 `x | (1 << k)` |
| [189] 轮转数组 | `forEach` 没有大写 | `forEach` 不是 `foreach` |
| [160] 相交链表 | 实例调用属性要加单引号 | 其实这是笔误级别的问题，写完扫一眼 |

## 三、指针 / 局部变量管理

| 题 | 你当时踩的坑 |
|---|---|
| [15] 三数之和 | **指针在外层循环结束后没有重置** |
| [11] 盛最多水 | 用 `for` 会多一个变量；双指针用 `while` 更清楚 |
| [11] 盛最多水 | `let` 定义 `area` 在 if 块里 → 外部访问不到（作用域）|
| [141] 环形链表 | 忘记用一个变量存"前面链表的头节点" |
| [438] 字母异位词 | 窗口不能重复创建（每次循环要复用/重置）|

### 口诀
> **外层循环跑完，内层指针必须重置**；变量声明提到最外层。

## 四、链表（你的弱区，坑最密集）

| 题 | 你当时踩的坑 |
|---|---|
| [206] 反转链表 | 链表不知道保存（`prev`/`curr`/`next` 三指针没想清）|
| [234] 回文链表 | 比较的是节点本身，不是 `val` |
| [21] 合并 | 空指针取 `val` |
| [2] 两数相加 | 不熟递归；`null` 取 `val` |
| [19] 删除倒数第 N | 本来可以用 **dummy 哨兵节点**，没用 |
| [24] 两两交换 | **dummy 写成 summy**（拼写错，找了半天）|
| [142] 环形链表 II | 不知道思路（快慢指针第二步）|
| [148] 排序链表 | 看不懂答案（归并排序 + 链表）|

### 口诀（链表四件事，每题先过一遍）
1. **先想 dummy 哨兵节点**（能省掉一堆"头节点特判"）
2. **先想三个指针怎么存**（`prev` / `curr` / `next`）
3. **每步问一句：我改了 `next` 之后，还能找到原来的下一个吗？**
4. **空链表 / 单节点**永远是第一组测试用例
